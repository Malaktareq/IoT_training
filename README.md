# IoT Training Program — Cyber Robot

This repository tracks daily work, code, and documentation for an IoT / Embedded Systems practical training program completed at **Cyber Robot** (Smart Industrial Automation), IoT Department.

- **Location:** Amman
- **Duration:** 19/07/2026 → 10/09/2026 (8 weeks)

## Repository Structure

Work is organized by **week**, and each week is broken down by **day**. Every day folder holds that day's technical report, firmware/code, and any schematics or reference images produced during that session.

```
IoT_training/
├── week1/
│   ├── day1_Sunday/
│   ├── day2_Monday/
│   ├── day3_Tuesday/
│   └── day4_Wednesday/
├── week2/
│   └── ...
├── week3/
│   └── ...
...
└── week8/
    └── ...
```

Each `dayN_<DayName>` folder generally contains:
- A daily technical report (objective, procedure, code, code breakdown, issues/troubleshooting, results)
- The firmware / source code written that day
- Any schematics, pinout references, or photos used or produced that day

As weeks progress, later folders may also include:
- `schematics/` — wiring diagrams and reference pinouts
- `README.md` — a summary specific to that week or project, where relevant

## Navigating This Repo

- Start at `week1/day1_Sunday/` for the first day of training and move forward chronologically through each week's day folders.
- Each daily report follows the same format for consistency: **Daily Overview → Task(s) → Objective → Procedure → Code / Configuration → Code Breakdown → Issues & Troubleshooting → Results & Outcome**.
- From Week 3 onward (Sensors, Relays, Motors), reports typically also include a **Schematics & Photos** section with wiring references and circuit diagrams.
